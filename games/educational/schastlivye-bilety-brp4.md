# Счастливые билеты — БРП-4

- Автор программы в руководстве не указан.
- Источник: «Электроника БРП-4». Руководство по эксплуатации, программа №38. [Архив руководства](https://arbinada.com/pmk/pages/01057-library-docs.html).
- Байт-код: [дамп BRP4-2.BIN, опубликованный myak555](https://github.com/myak555/MK-52_Resurrect/blob/main/MK-52_Sample_Programs/BRP%20Expansion%20Modules/BRP4-2.BIN); автор дампа — Сергей Фролов.
- Исходный адрес загрузки: `1110698`, переключатель БРП в положении `2`.
- Программа: [schastlivye-bilety-brp4.txt](schastlivye-bilety-brp4.txt)
- Модель: **МК-61**; объём: **98 команд**, адреса `00…97`.

## Опыт со счастливыми билетами

Шестизначный билет считается счастливым, если сумма первых трёх цифр равна сумме последних трёх. Программа перебирает заданный **включительный** интервал номеров и либо выдаёт все счастливые билеты, либо сразу считает их количество. Номера меньше 100000 мысленно дополняют слева нулями.

## Подготовка

Введите листинг, перейдите в `F АВТ`:

```text
123105 хП4
123155 хП7
42 хП8
В/О С/П
```

Появится первый счастливый номер `123105`. Угловой режим произвольный. Начальная граница в `R4`, конечная в `R7`, режим в `R8`; допустимо `0 ≤ N1 ≤ N2 ≤ 999999`, целые значения.

## Режимы и контроль

- `R8=42`: каждое `С/П` выдаёт следующий счастливый номер. После последнего появляется их **количество**. У исходного листинга нет отдельного графического признака этой последней остановки: количество сверяйте с `R9`.
- `R8=43`: программа выдаёт только количество, хранящееся в `R9`.

Для примера выше последовательность: `123105, 123114, 123123, 123132, 123141, 123150`, затем итог `6`. С режимом 43 сразу появится `6`.

Перебор большого интервала занимает много времени. Для нового расчёта заново задайте обе границы и режим, затем `В/О С/П`. Служебные `R0…R3`, `R5`, `R6`, `Ra…Rc` изменяются; `R4` в ходе перебора тоже меняется.
