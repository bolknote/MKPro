## Подготовка

```text
0.1234
```

## Игра

Переключатель — `Р`. Нажмите `В/О С/П`: появится `0`.
После следующего `С/П` запомните три последовательно показанных числа.
Между ними и после третьего числа выводится разделитель `1,1111111`.
Введите `первое В↑ второе В↑ третье С/П`.

Результат — число верных ответов, через `↔` — сколько попыток осталось.
Нажмите `С/П` для следующего задания. После ошибки тройка повторяется,
после верного ответа одно из чисел усложняется на один разряд.
После 20 попыток выводится `ЕГГОГ`; итоговый счёт находится в R5.
Новая партия — новое дробное зерно и `В/О С/П`.

## Сверка

105 команд восстановлены по печатной таблице. Исправлен порядок блоков старого импорта.
Ответы сравниваются по сумме модулей ошибок: взаимное сокращение ошибок двух чисел не даёт победы.


Начальная разрядность — один знак; по сравнению с версией 1М интерфейс требует больше шагов
для показа чисел. Параметр количества попыток находится в командах **38–39**.
