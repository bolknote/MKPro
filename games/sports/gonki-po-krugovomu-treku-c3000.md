# Гонки по круговому треку

- Автор: Я. К. Трохименко
- Первоисточник: Я. К. Трохименко, «Игры с микро-ЭВМ». Киев: «Техніка», 1986.
- Архивная копия: [«Калькуляторы 3000» 6.2](http://old-dos.ru/index.php?page=files&mode=files&do=show&id=4952)
- Автор карточки C3000: Andriy Slezenko, student@uninet.kiev.ua
- Исходный файл: `Game3.c3`
- Модель: МК-61
- Программа: [gonki-po-krugovomu-treku-c3000.txt](gonki-po-krugovomu-treku-c3000.txt)

## Описание из карточки C3000

Установить переключатель Р-Г в положение Г, ввести d=РА; R=РВ; Rmin^2=РС; Rmax^2=РД и нажать клавиши БП 62 С/П; после каждого выполнения программы высвечивается номер участника гонок, который вводит в регистр X выбранное значение угла "фи" направления движения и нажимает только клавишу С/П; текущие координаты участников хранятся в регистрах Р7=xiштрих ("икс итое штрих"); Р8=yiштрих ("игрек итое штрих") и Р4=xiштрих-штрих; Р5=yiштрих-штрих; выигрывает первым достигший линии старта.
