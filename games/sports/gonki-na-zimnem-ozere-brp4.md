# Гонки на зимнем озере — БРП-4

- Автор программы в руководстве не указан.
- Источник: «Электроника БРП-4». Руководство по эксплуатации, программа №45. [Архив руководства](https://arbinada.com/pmk/pages/01057-library-docs.html).
- Байт-код: [дамп BRP4-2.BIN, опубликованный myak555](https://github.com/myak555/MK-52_Resurrect/blob/84693a122a2737169257edf6565b1aa8814b742e/MK-52_Sample_Programs/BRP%20Expansion%20Modules/BRP4-2.BIN); автор дампа — Сергей Фролов.
- Исходный адрес загрузки: `1232491`, переключатель БРП в положении `2`.
- Программа: [gonki-na-zimnem-ozere-brp4.txt](gonki-na-zimnem-ozere-brp4.txt)
- Модель: **МК-61**; объём: **91 команда**, адреса `00…90`.

## Правила

Аэросани едут по ледяной дорожке шириной 6 единиц. Порывистый ветер сносит их к обочине. На каждом ходу задают приращение скорости и угол руля `−90…90°`. Длину дистанции выбирают от 20 до 50; задача — быстрее достичь финиша с меньшим числом штрафов.

БРП-4 содержит отдельную редакцию [«Гонок на зимнем озере»](gonki-na-zimnem-ozere.md): её байт-код и расчёт сноса отличаются от журнального листинга.

## Подготовка

Введите листинг, перейдите в `F АВТ`, переключатель углов установите в **`Г` (градусы)**:

```text
В/О 20 С/П
```

Появится `3` — начальное расстояние до левой обочины. Инициализация задаёт нулевую скорость, путь и штрафы, а также начальное состояние ветра.

## Ход

Введите приращение скорости `ΔV`, нажмите `В↑`, введите угол и нажмите `С/П`. Например, `1 В↑ 0 С/П`. Программа покажет расстояние до левого края; через `↔` можно увидеть скорость. Для каждого следующего хода повторяйте ввод пары.

В примере последовательные пары `(1,0)`, `(1,3)`, `(1,45)` дают расстояния примерно `2,81809`, `1,71286`, `2,02449` и скорости `1,2,3`.

## Штрафы и финиш

`ЕГГ0Г` — предусмотренная остановка. Нажмите `С/П`, чтобы увидеть причину, затем ещё одно `С/П`, чтобы вернуться к обычной остановке с расстоянием. После этого вводите следующую пару управления.

- `π`: приращение скорости по модулю больше единицы; повторите ввод с допустимым приращением.
- `0`: скорость стала нулевой; задайте разгон.
- Значение вне `0…6`: выезд на обочину. Программа обнуляет скорость и возвращает сани на ось; задайте новую пару и продолжите.

Достижение финиша показывается длиной дистанции (`20` в примере). После него новую партию начинайте полной подготовкой.

| Регистр | Значение |
| --- | --- |
| `R1` | длина дистанции |
| `R2` | пройденный путь |
| `R5` | штрафы |
| `R6` | счётчик времени, включая начальную остановку |
| `R7` | состояние генератора ветра |
| `R8` | расстояние до левого края |
| `R9` | скорость |
| `R0` | число внутренних шагов движения |

`R3`, `R4`, `Rd` — рабочие значения. Штрафы за слишком резкое изменение скорости и за выезд предусмотрены самим листингом; дополнительных проверок формата ввода нет.
