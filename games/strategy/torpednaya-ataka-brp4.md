# Торпедная атака — БРП-4, исправленная версия

- Автор программы в руководстве не указан.
- Источник: «Электроника БРП-4». Руководство по эксплуатации, программа №48. [Архив руководства](https://arbinada.com/pmk/pages/01057-library-docs.html).
- Исходный байт-код: [дамп BRP4-2.BIN, опубликованный myak555](https://github.com/myak555/MK-52_Resurrect/blob/84693a122a2737169257edf6565b1aa8814b742e/MK-52_Sample_Programs/BRP%20Expansion%20Modules/BRP4-2.BIN); автор дампа — Сергей Фролов.
- Исходный адрес загрузки: `1289898`, переключатель БРП в положении `2`.
- Программа: [torpednaya-ataka-brp4.txt](torpednaya-ataka-brp4.txt)
- Модель: **МК-61**; объём: **105 команд**, адреса `00…99`, `A0…A4`.

## Правила

Вы командуете неподвижной подводной лодкой с **десятью торпедами**. Корабли противника появляются со случайным пеленгом `100…119°` и скоростью `15…34` узла. Скорость торпеды — 75 узлов. Задайте угол упреждения, чтобы торпеда встретилась с движущейся целью. Попадание засчитывается при разности углов меньше 2°.

В этой версии исправлена ошибка исходного ПЗУ, из-за которой десятая торпеда не участвовала в расчёте. Все изменения перечислены ниже.

Это другая программа, чем [«Торпедная атака» из тетради Долгушина](torpednaya-ataka-dolgushin-notebook.md): здесь есть генератор целей, боезапас и счёт потопленных кораблей.

## Подготовка

Введите листинг, перейдите в `F АВТ`, установите угловой режим **`Г` (градусы)**:

```text
0,2 хП0
В/О С/П
```

Появится `10700028`: первые три цифры — пеленг 107°, последние две — скорость 28 узлов; промежуточные нули служебные. В `R0` можно задавать другое начальное число строго между 0 и 1.

## Стрельба

Введите угол пуска `α` и `С/П`. Допустимо `0 < α < φ`, где `φ` — текущий пеленг; нулевой угол вызывает деление на ноль.

| Показание | Действие |
| --- | --- |
| `5,5555555` | Корабль потоплен; `С/П` вызывает новую цель, а после десятой торпеды показывает итог |
| `1,1111111` | Корабль ушёл за границу сектора; `С/П` вызывает новую цель, а после десятой торпеды показывает итог |
| Целый угол при `R7>0` | Промах; показан новый пеленг той же цели, можно стрелять снова |
| Целое число `0…10` при `R7=0` | Итог: число потопленных кораблей, партия закончена |

Контроль: `86 С/П → 5,5555555`; `С/П → 11900028`; `98 С/П → 101`; `80 С/П → 5,5555555`. Потоплено два корабля, осталось семь торпед. При промахе десятой торпедой итог появляется сразу.

## Исправления относительно ПЗУ

Руководство обещает 10 торпед. В ПЗУ счётчик действительно начинается с 10, но после его уменьшения код проверяет окончание **до расчёта выстрела**. Поэтому исходная программа рассчитывает только девять пусков, а десятый ввод сразу показывает итог.

В каталоге опубликована исправленная версия:

- команды `26…27` заменены на `НОП`, преждевременная проверка убрана;
- проверка после сообщения о попадании или уходе цели помещена в `72…77`, ветка ухода перенесена в `95…98`;
- переход после промаха направлен в `99…A4`: пока есть торпеды, показывается пеленг, после последней — итог.

Листинг занимает 105 команд вместо исходных 98. Генератор, расчёт движения и порог попадания сохранены. В эмуляторе проверены полные партии из десяти пусков со всеми тремя исходами последнего выстрела; максимальный результат теперь **10**.

`R7` — оставшийся счётчик, `R8` — текущий пеленг, `R9` — скорость цели, `R4` — потопленные корабли, `R5` — угол последнего пуска. После итога `В/О С/П` начинает новую партию с текущим состоянием генератора; для воспроизводимого повтора снова выполните полную подготовку. Ошибки угла отдельно не проверяются.
