# Торпедная атака — БРП-4

- Автор программы в руководстве не указан.
- Источник: «Электроника БРП-4». Руководство по эксплуатации, программа №48. [Архив руководства](https://arbinada.com/pmk/pages/01057-library-docs.html).
- Байт-код: [дамп BRP4-2.BIN, опубликованный myak555](https://github.com/myak555/MK-52_Resurrect/blob/main/MK-52_Sample_Programs/BRP%20Expansion%20Modules/BRP4-2.BIN); автор дампа — Сергей Фролов.
- Исходный адрес загрузки: `1289898`, переключатель БРП в положении `2`.
- Программа: [torpednaya-ataka-brp4.txt](torpednaya-ataka-brp4.txt)
- Модель: **МК-61**; объём: **98 команд**, адреса `00…97`.

## Правила

Вы командуете неподвижной подводной лодкой. Корабли противника появляются со случайным пеленгом `100…119°` и скоростью `15…34` узла. Скорость торпеды — 75 узлов. Задайте угол упреждения, чтобы торпеда встретилась с движущейся целью. Попадание засчитывается при разности углов меньше 2°.

Это другая программа, чем [«Торпедная атака» из тетради Долгушина](torpednaya-ataka-dolgushin-notebook.md): здесь есть генератор целей, боезапас и счёт потопленных кораблей.

## Подготовка

Введите листинг, перейдите в `F АВТ`, установите угловой режим **`Г` (градусы)**:

```text
0,2 хП0
В/О С/П
```

Появится `10700028`: первые три цифры — пеленг 107°, последние две — скорость 28 узлов; промежуточные нули служебные. В `R0` можно задавать другое начальное число строго между 0 и 1.

## Стрельба

Введите угол пуска `α` и `С/П`. Допустимо `0 < α < φ`, где `φ` — текущий пеленг; нулевой угол вызывает деление на ноль.

| Показание | Действие |
| --- | --- |
| `5,5555555` | Корабль потоплен; `С/П` вызывает новую цель |
| `1,1111111` | Корабль ушёл за границу сектора; `С/П` вызывает новую цель |
| Целый угол | Промах; показан новый пеленг той же цели, можно стрелять снова |
| Целое число потопленных при `R7=0` | Партия закончена |

Контроль: `86 С/П → 5,5555555`; `С/П → 11900028`; `98 С/П → 101`; `80 С/П → 5,5555555`. Потоплено два корабля, осталось семь единиц счётчика.

## Особенность исходного боезапаса

Руководство обещает 10 торпед. В ПЗУ счётчик действительно начинается с 10, но уменьшается **до** проверки окончания. При десятом вводе программа сразу показывает итог и уже не рассчитывает попадание: фактически доступны **девять результативных выстрелов**. Это поведение сохранено и проверено; десятый ввод завершает партию.

`R7` — оставшийся счётчик, `R8` — текущий пеленг, `R9` — скорость цели, `R4` — потопленные корабли, `R5` — угол последнего пуска. После итога `В/О С/П` начинает новую партию с текущим состоянием генератора; для воспроизводимого повтора снова выполните полную подготовку. Ошибки угла отдельно не проверяются.
