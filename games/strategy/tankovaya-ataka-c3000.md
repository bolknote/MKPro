# Танковая атака

- Автор: Я. К. Трохименко
- Первоисточник: Я. К. Трохименко, «Игры с микро-ЭВМ». Киев: «Техніка», 1986. Программа 43, с. 91–92.
- Архивная копия: [«Калькуляторы 3000» 6.2](http://old-dos.ru/index.php?page=files&mode=files&do=show&id=4952)
- Автор карточки C3000: Andriy Slezenko, student@uninet.kiev.ua
- Исходный файл: `Game8.c3`
- Модель: МК-61
- Программа: [tankovaya-ataka-c3000.txt](tankovaya-ataka-c3000.txt)

## Описание

Это усложнённая навесная стрельба по приближающейся цели. После каждого выстрела танк изменяет расстояние до орудия на заданную величину `Δdц`, поэтому найденный прежде угол уже не обязательно подходит для следующего хода.

Игрок последовательно задаёт угол возвышения, ориентируясь по выдаваемому расстоянию между целью и местом разрыва. Цель — остановить атаку за минимальное число выстрелов; программу можно также использовать для поочерёдного боя орудия с танком. Попадание обозначается `ЕГГОГ`.

## Подготовка, запуск и правила

Установить переключатель Р-Г в положение Г; ввести начальную дальность до цели dц0=Р7, радиус поражения "дельта"=Р8, максимальную дальность стрельбы dmax=Р9, изменение расстояния до цели за время полета снаряда дельтаdц=Р6; очистить регистр 4; перед каждым пуском программы нажатием клавиши С/П (первый раз - клавиш В/О и С/П) вводить угол возвышения "фи большое"=РX; после выполнения программы высвечивается расстояние между целью и местом падения снаряда или, при поражении цели - сигнал ЕГГОГ; число выстрелов хранится в регистре 4.

## Состояние регистров в исходном `.c3`

В сохранённом снимке `R0…Re` равны нулю. Скрытых начальных констант в файле нет: перед первым пуском нужно выполнить подготовку из раздела выше.
