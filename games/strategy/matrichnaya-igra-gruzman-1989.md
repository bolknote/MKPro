# Матричная игра n×n

- Автор программы: в таблице источника не указан
- Источник: М. З. Грузман, «Логические игры с калькулятором». Москва: Просвещение, 1989, с. 138–140
- Дата в паспорте программы: 20.07.83
- Исходная модель: «Электроника Б3-34»
- Программа: [matrichnaya-igra-gruzman-1989.txt](matrichnaya-igra-gruzman-1989.txt)

## Правила

Игрок `A` тайно выбирает строку платёжной матрицы, игрок `B` — столбец. После того как выбор открыт, программа показывает элемент `aᵢⱼ`: положительное значение означает выигрыш `A`, отрицательное — выигрыш `B`. Одновременно программа накапливает сумму результатов с точки зрения игрока `A`.

Из-за числа доступных регистров листинг рассчитан на матрицы `2×2` и `3×3`.

## Подготовка

1. Занести элементы матрицы построчно:
   - для `2×2`: `a11 → R1`, `a12 → R2`, `a21 → R3`, `a22 → R4`;
   - для `3×3`: `a11…a33 → R1…R9`.
2. Занести размер матрицы `n` в `R0`.
3. Занести `0` в `RС` — это начальная сумма игрока `A`.

Переключатель `Р–Г` установить в положение `Р`.

## Партия

1. Игрок `A`, не показывая выбор игроку `B`, заносит номер строки `i` в `RА` и стирает индикатор.
2. Игрок `B` заносит номер столбца `j` в `RВ`.
3. Нажать `В/О`, `С/П`. На индикаторе появится соответствующий элемент `aᵢⱼ`.
4. Повторить оговорённое число партий.
5. Нажать `ПхС`: положительная сумма означает победу `A`, отрицательная — победу `B`, ноль — ничью.

`RД` используется как вычисляемый номер регистра с элементом матрицы.
