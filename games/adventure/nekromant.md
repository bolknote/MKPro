# Некромант

- Автор и источник: [Serge Anvarov, «Некромант»](https://sergeanvarov.github.io/russian/mk61/games/%D0%BD%D0%B5%D0%BA%D1%80%D0%BE%D0%BC%D0%B0%D0%BD%D1%82/%D0%BD%D0%B5%D0%BA%D1%80%D0%BE%D0%BC%D0%B0%D0%BD%D1%82.html)
- Программа: [nekromant.txt](nekromant.txt)

## Предыстория

Вы некромант и договорились с местными жителями успокоить неспокойное
кладбище за вознаграждение. Ночью вы подготовили и запустили мощное
заклинание, привязанное к вам и к месту. Оно сработает примерно через
25 минут, а уйти до этого нельзя.

Почуяв угрозу, зомби начали выбираться из могил и медленно приближаться с
обеих сторон. Из-за основного заклинания вы видите лишь на три метра. Для
защиты можно направить всю силу разрывного заклинания в одну сторону либо
рассеять более слабый удар в обе стороны. Два амулета автоматически
уничтожат добравшихся до вас мертвецов, но третий контакт станет
смертельным.

## Задача и поле

Нужно продержаться 25 ходов-минут до завершения основного заклинания.

Поле выводится примерно как `3.CГ 8 E`:

- первая цифра показывает оставшееся число допустимых контактов;
- `8` в центре обозначает игрока;
- по три позиции слева и справа показывают приближающихся монстров;
- в регистре `Y` находится число минут до победы.

За ход появляется не более одного нового монстра: слева, справа либо не
появляется вовсе. Ближайший к игроку монстр в каждой группе находится у
центра экрана. Уровни силы от слабого к сильному обозначены `L`, `C`, `Г`,
`E`.

## Заклинания

Введите число и нажмите `С/П`:

| Ввод | Действие |
| ---: | --- |
| `< 0` | сосредоточенный удар влево |
| `0` | рассеянный удар в обе стороны |
| `> 0` | сосредоточенный удар вправо |

Удар действует только на ближайшего монстра с выбранной стороны, независимо
от расстояния до него. Остальные продолжают движение.

| Монстр до удара | Рассеянный удар | Сосредоточенный удар |
| --- | --- | --- |
| `L` | превращается в `C` | превращается в `Г` |
| `C` | превращается в `Г` | превращается в `E` |
| `Г` | превращается в `E` | уничтожается |
| `E` | уничтожается | остаётся `E` |

Слабый `E`-монстр использует избыток сосредоточенной силы для восстановления,
поэтому такой удар на него не действует.

## Подготовка

Если состояние эмулятора не содержит заранее заполненных регистров, один раз
введите следующие значения:

| Регистр | Значение |
| --- | --- |
| `Р4` | служебное значение, набираемое последовательностью `5 5 К ИНВ К{x} ВП 1 К[x] хП4` |
| `Р5` | произвольное число от `0` до `1`, начальное состояние генератора |
| `Р6` | `25` |
| `Р7` | `74` |
| `Р8` | `83` |
| `Р9` | `92` |
| `Рb` | `53` |
| `Рc` | `96` |
| `Рe` | `1000` |

Для начала игры нажмите `В/О`, `С/П`.

## Ход игры

После остановки на экране показано поле, а в `Y` - оставшееся время. Введите
направление заклинания и нажмите `С/П`. Программа применит удар, передвинет
всех выживших монстров на один метр к игроку, уменьшит время и подготовит
следующий ход.

Если монстр добрался до игрока, появляется сообщение `--.`. Нажмите `С/П`:
амулет уничтожит монстра, число допустимых контактов уменьшится, и игра
продолжится. После третьего контакта игра заканчивается поражением.

Если удалось пережить последнюю минуту, на экране появляется `1000` -
вознаграждение за работу. Новая игра запускается командами `В/О`, `С/П`.

## Настройка сложности

- Команда по адресу `01` задаёт начальное число допустимых контактов; в
  исходном варианте это `3`, то есть два амулета и смертельный третий контакт.
- `Р6` задаёт продолжительность игры в минутах; исходное значение равно `25`.

## Регистры

| Регистр | Назначение |
| --- | --- |
| `Р0` | левая группа монстров |
| `Р1` | оставшееся время |
| `Р2` | оставшееся число допустимых контактов |
| `Р3` | счётчик цикла, затем сила выбранного удара |
| `Р4` | служебная константа и множитель `10` |
| `Р5` | состояние генератора псевдослучайных чисел |
| `Р6` | начальная продолжительность игры |
| `Р7` | адрес подпрограммы сдвига группы, `74` |
| `Р8` | адрес подпрограммы удара, `83` |
| `Р9` | адрес подпрограммы замены первой цифры, `92` |
| `Рa` | правая группа монстров |
| `Рb` | адрес ветви рассеянного удара, `53` |
| `Рc` | адрес генератора случайных чисел, `96` |
| `Рd` | выбор группы: `0` или `10` |
| `Рe` | константа `1000`, признак победы и косвенный возврат к адресу `00` |

## Логика программы

Монстры каждой стороны хранятся тремя десятичными цифрами. Ближайший к
игроку монстр занимает старший разряд. Умножение группы на `10` передвигает
её к центру; появившаяся целая часть означает контакт, а дробная часть вновь
сохраняется как группа.

Генератор использует рекуррентную формулу
`N(i+1) = frac(7 * N(i) + pi)`. Результат умножается на `2` для выбора
стороны и на `5` для выбора уровня нового монстра; нулевой уровень означает,
что в эту минуту никто не появился.

Внутри программы уровни представлены цифрами `4`, `3`, `2`, `1`, которые
после `К ИНВ` отображаются как `L`, `C`, `Г`, `E`. Рассеянный удар вычитает
единицу, сосредоточенный - двойку, а модуль результата реализует иммунитет
`E` к сосредоточенному удару. Подпрограмма с адреса `92` (`<->`, `F↻`,
`ВП`, `В/О`) использует стек и `X2`, чтобы заменить первую значащую цифру
группы без отдельного длинного цикла.
