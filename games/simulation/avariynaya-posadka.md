# Аварийная посадка (БП 86)

- Автор: **darth.righter**
- Источник: [«Аварийная посадка (БП 86)»](https://darth-righter.livejournal.com/9406.html)
- Программа: [avariynaya-posadka.txt](avariynaya-posadka.txt)
- Серия: «Лунная посадка»

## Сюжет и задача

Грузовой космический корабль выходит к Луне, но его маршевый двигатель не отключается вовремя. Горизонтальная скорость погашена, основные баки почти пусты, а корабль начинает падать на поверхность. Пилот и пассажирка переходят в автономный спасательный модуль «Борт 86», системой управления которого служит «Электроника МК-61».

Нужно посадить модуль на Луну, управляя расходом топлива и продолжительностью включения двигателя. Горизонтальное движение не моделируется. Мягкой считается посадка с вертикальной скоростью не более 5 м/с по модулю.

Начальную высоту программа выбирает случайно в пределах 10 км. Запас топлива рассчитывается для этой высоты и позволяет совершить мягкую посадку, но почти не оставляет права на ошибку. Модель учитывает массу модуля и топлива, скорость истечения продуктов сгорания, лунное притяжение и ограничение по перегрузке.

## Подготовка

Введите исходные данные:

```text
1.62 xП4
1200 xП5
3660 xП6
9.81 В↑ 3 × xП7
Cx ÷ ВП ВП xП9
0 xПB
```

Здесь заданы:

| Регистр | Значение |
|---|---|
| `Р4` | ускорение свободного падения, м/с²; для Луны — `1,62` |
| `Р5` | масса модуля с экипажем без топлива, кг; в примере — `1200` |
| `Р6` | скорость истечения продуктов сгорания, м/с; в примере — `3660` |
| `Р7` | предельно допустимое реактивное ускорение, м/с²; в примере — `3g`, или `29,43` |
| `Р9` | сообщение об аварийной ситуации; последовательность выше записывает букву `Г` |
| `РВ` | начальная вертикальная скорость, м/с; перед первым запуском — `0` |

Запустите новую попытку:

```text
БП 86 С/П
```

При первой остановке на индикаторе будет начальная высота. В регистре стека `Y` находится исходный запас топлива; позднее остаток топлива можно посмотреть командой `ПxD`.

## Управление двигателем

Каждый манёвр задаётся двумя числами:

```text
масса_топлива ПП время С/П
```

Первое число — масса топлива в килограммах, которую требуется израсходовать, второе — продолжительность работы двигателя в секундах. Для свободного падения укажите нулевой расход.

После расчёта очередного участка программа показывает текущую высоту. В регистре стека `Y` находится вертикальная скорость; её также можно вызвать командой `ПxB`. Положительная скорость направлена вверх, отрицательная — к поверхности.

Полезные регистры во время полёта:

| Регистр | Значение |
|---|---|
| `Р1` | заданная масса топлива для последнего манёвра, кг |
| `Р2` | продолжительность последнего манёвра; после перегрузки — время отключения двигателя, с |
| `Р8` | реактивное ускорение при последнем включении двигателя, м/с² |
| `РА` | текущая высота, м |
| `РВ` | текущая вертикальная скорость, м/с |
| `РД` | оставшийся запас топлива, кг |

Если запрошено больше топлива, чем осталось, двигатель сохранит заданный секундный расход, но выключится раньше — при полном опустошении бака.

## Аварийный сигнал

Сообщение `Г` означает нехватку топлива или превышение допустимой перегрузки. Нажмите `С/П`, чтобы продолжить расчёт.

При перегрузке двигатель завершает заданный манёвр, после чего пилот на некоторое время теряет сознание. Пока управление недоступно, модуль падает с выключенным двигателем. Продолжительность этого участка можно посмотреть командой `Пx2`: чем сильнее превышен предел из `Р7`, тем дольше отключение.

## Посадка и повреждения

Ноль на индикаторе означает касание поверхности. Нажмите `↔`, чтобы увидеть в `X` конечную вертикальную скорость, ранее находившуюся в `Y`.

- До `5` м/с по модулю — мягкая посадка.
- Свыше `5`, но не более `7` м/с — на экране `ЕГГОГ`: модуль цел, экипаж отделался ушибами.
- Свыше `7`, но не более `8,7` м/с — на экране `ЗГГОГ`: экипаж травмирован, стек возвратов повреждён и требует восстановления.
- Свыше `8,7` м/с — программа показывает повреждённый участок собственного кода. Команда `FПРГ` переводит калькулятор в мерцающее неуправляемое состояние; для обычного перезапуска потребуется выключить ПМК и заново ввести программу и данные.

После посадки без тяжёлых повреждений можно начать новую тренировку командой `БП 86 С/П`. Перед повтором обнулите вертикальную скорость:

```text
0 xПB
```

## Пример мягкой посадки

После подготовки из примера автор приводит такую последовательность:

```text
БП 86 С/П
```

На индикаторе: высота `4040,67` м; в `Y`: `38,1` кг топлива.

Сначала модуль свободно падает 69 секунд:

```text
0 ПП 69 С/П
```

Затем используется весь оставшийся запас за 3,18 секунды:

```text
ПxD ПП 3.18 С/П
```

Появится `Г`, поскольку допустимая перегрузка превышена. После `С/П` программа покажет высоту `0`; команда `↔` выдаст скорость около `−4,1` м/с — посадка мягкая.
