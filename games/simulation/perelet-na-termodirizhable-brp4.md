# Перелёт на термодирижабле — БРП-4

- Автор программы в руководстве не указан.
- Источник: «Электроника БРП-4». Руководство по эксплуатации, программа №50. [Архив руководства](https://arbinada.com/pmk/pages/01057-library-docs.html).
- Байт-код: [дамп BRP4-2.BIN, опубликованный myak555](https://github.com/myak555/MK-52_Resurrect/blob/84693a122a2737169257edf6565b1aa8814b742e/MK-52_Sample_Programs/BRP%20Expansion%20Modules/BRP4-2.BIN); автор дампа — Сергей Фролов.
- Исходный адрес загрузки: `1315098`, переключатель БРП в положении `2`.
- Программа: [perelet-na-termodirizhable-brp4.txt](perelet-na-termodirizhable-brp4.txt)
- Модель: **МК-61**; объём: **98 команд**, адреса `00…97`.

## Задача

Доставьте груз на термодирижабле по выбранному на карте маршруту, стараясь сократить время и расход топлива. Горизонтальное движение зависит от мощности двигателя и ветра, высота — от подъёмной силы воздушного баллонета. Обогрев и подъёмная сила меняются постепенно.

Это самостоятельная редакция БРП-4 [«Термодирижабля»](termodirizhabl.md): в ней используются экспоненциальные зависимости и деление; байт-код отличается от журнальной записи каталога.

## Подготовка

Введите листинг, перейдите в `F АВТ`. Контрольный запуск из руководства:

```text
500 хП0
5000 хП1
1 хП2
10000 хП3 хПd
2000 хП4
12000 хП5
0 хП6 хП8 хПa хПb
1000 хП7
10 /-/ хП9
1 /-/ хПc
В/О С/П
```

Появится высота около `1417,7838` м. Через `↔` доступна скорость `101,8034` км/ч. Положение переключателя углов произвольное. `Rc=−1` задаёт удобный числовой сигнал окончания топлива; руководство предлагает буквенный `Е00`.

## Управление и регистры

Перед следующим `С/П` при необходимости изменяйте управляющие значения:

| Регистр | Значение |
| --- | --- |
| `R0` | мощность двигателя, л. с. |
| `R1` | заданное превышение подъёмной силы над переменной массой, кг |
| `R2` | шаг времени, ч, `0 < Δt ≤ 3` |
| `R3` | груз, кг |
| `R4` | оставшееся топливо, кг |
| `R5` | подъёмная сила, кг |
| `R6` | фактическое превышение подъёмной силы над массой |
| `R7` | высота, м |
| `R8` | скорость, км/ч |
| `R9` | ветер, км/ч: минус — встречный |
| `Ra`, `Rb` | суммарная дальность и время |
| `Rc` | сигнал окончания топлива |
| `Rd` | постоянная `10000` |

Для взлёта задают положительное `R1`, для стабилизации высоты — ноль или отрицательное значение, для посадки руководство предлагает `−1000`. `0 хП5` ускоряет снижение. При исчерпании топлива появляется выбранный сигнал `−1`; после `С/П` аппарат дрейфует и снижается.

Руководство рекомендует мощность до 100 л. с., но его контрольный пример использует 500; это намеренно сохранено в приведённом запуске. В примере после первого шага остаётся 1780 кг топлива, дальность около 101,8034 км, время 1 ч. Препятствия и выполнение задания отмечают на бумажной карте. Новую попытку начинайте с полной подготовки.
