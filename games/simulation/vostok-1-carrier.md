# Восток-1: Ракета-Носитель

- Автор: **darth.righter**
- Первоисточник: [«Полёт Гагарина на ПМК»](https://darth-righter.livejournal.com/5756.html)
- Зеркало: [Arbinada — «ВОСТОК-1 на МК61»](https://pmk.arbinada.com/category/01621.html)
- Программа: [vostok-1-carrier.txt](vostok-1-carrier.txt)
- Основа: программа Михаила Пухова «Атмосфера-1», *Техника — молодёжи*, № 3, 1986

## Назначение

«Ракета-Носитель» моделирует первые 119 секунд старта «Востока-1», когда центральный блок А и четыре боковых блока Б, В, Г и Д работают одновременно. После этого боковые блоки отделяются, а дальнейший полёт рассчитывается программой «Атмосфера».

В отличие от исходной «Атмосферы-1», программа учитывает изменение эффективного удельного импульса двигателя с высотой. Это позволяет моделировать первую ступень при быстром изменении атмосферного давления.

Расчёт выполняется с постоянным шагом в одну секунду. Вектор тяги задаётся углом относительно текущего направления скорости: `0` означает, что тяга направлена вдоль траектории.

## Регистры

| Регистр | Значение |
|---|---|
| `Р0` | горизонтальная скорость относительно поверхности |
| `Р1` | счётчик циклов автопилота |
| `Р2` | отклонение вектора тяги от текущего направления скорости |
| `Р3` | отклонение текущей скорости от вертикали |
| `Р4` | гравитационный параметр планеты |
| `Р5` | сухая масса ракеты, кг |
| `Р6` | целая часть — максимальная скорость истечения в вакууме; дробная — относительное уменьшение у поверхности |
| `Р7` | радиус планеты, м |
| `Р8` | служебный; при остановке — аэродинамическое ускорение, делённое на скорость |
| `Р9` | расход топлива, кг/с |
| `РА` | расстояние до центра планеты, м |
| `РВ` | вертикальная скорость |
| `РС` | горизонтальное смещение от точки старта |
| `РД` | запас топлива, кг |
| `РЕ` | целая часть — масштаб атмосферы; дробная — величина, обратная аэродинамическому параметру ракеты |

## Исходные данные первой ступени

```text
6371 ВП 3 xП7
Fx² 9,81 × xП4
ИП7 100 + xПA
1 xП1
0,0001 xПB
0 xП0 xПC
92129 xП5
3023,1863 xП6
1637,5 xП9
194866 xПD
17500,046 xПE
```

Начальная высота здесь равна примерно 100 м. Расчётные параметры объединяют центральный блок и четыре боковых: расход топлива составляет `1637,5` кг/с, а эффективная скорость истечения меняется от земного значения к вакуумному максимуму `3023` м/с.

## Управление полётом

После ввода исходных данных нажмите `В/О С/П`. При остановке:

- `X` показывает отклонение траектории от вертикали;
- `Y` показывает текущую высоту.

Манёвр вводится так:

```text
угол_тяги ПП продолжительность_в_секундах С/П
```

Время должно быть целым числом: автопилот самостоятельно разбивает манёвр на секундные шаги. После исчерпания топлива программа выдаёт `ЕГГОГ` на адресе 49.

На 119-й секунде отделите боковые блоки. Для перехода к следующему этапу выполните `1 xП1 В/О С/П`: программа зафиксирует скорости и координаты, которые затем использует «Атмосфера».
