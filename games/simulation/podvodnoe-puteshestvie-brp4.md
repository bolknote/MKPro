# Подводное путешествие — БРП-4

- Автор программы в руководстве не указан.
- Источник: «Электроника БРП-4». Руководство по эксплуатации, программа №47. [Архив руководства](https://arbinada.com/pmk/pages/01057-library-docs.html).
- Байт-код: [дамп BRP4-2.BIN, опубликованный myak555](https://github.com/myak555/MK-52_Resurrect/blob/main/MK-52_Sample_Programs/BRP%20Expansion%20Modules/BRP4-2.BIN); автор дампа — Сергей Фролов.
- Исходный адрес загрузки: `1270298`, переключатель БРП в положении `2`.
- Программа: [podvodnoe-puteshestvie-brp4.txt](podvodnoe-puteshestvie-brp4.txt)
- Модель: **МК-61**; объём: **98 команд**, адреса `00…97`.

## Задача

Управляйте исследовательским аппаратом «Эльвин»: меняйте ход, курс и сбрасывайте балласт, чтобы найти цель по гидроакустическим данным. Программа ведёт глубину, относительные координаты буя и цели и оставшийся ресурс. Превышение предельной глубины, удар о дно или исчерпание ресурса вызывают аварийное всплытие.

Это редакция БРП-4 программы [«Подводные аппараты»](podvodnye-apparaty.md). **Указанная в руководстве замена команды `18: хП9` на `18: Пх9` уже выполнена в листинге.** Остальные байты сохранены.

## Подготовка

Введите листинг, перейдите в `F АВТ`, установите угловой режим **`Г`**:

```text
3 хП2
13000 хП3
1000 хП4 хП5
1200 хП6 хП7
720 хП8
0 хП9
3001 хПa
3500 хПb
1 /-/ хПc
2 /-/ хПd
Cx В/О С/П
```

Первое показание — `0`, аппарат ожидает команду. Для удобства ручного ввода в этом запуске выбраны числовые сигналы: `−1` — авария, `−2` — цель найдена. Они задаются данными в `Rc`, `Rd`; исходное руководство использует буквенные сигналы `Г`, `Е00`.

## Управление

Введите **ход `V` от 0 до 10**, нажмите `ПП`; введите курс в градусах и снова `ПП`; введите массу сбрасываемого балласта `Δp` и нажмите `С/П`. Здесь `ПП` вводит параметры через стек возвратов — заменять его на `В↑` нельзя.

Контрольный манёвр:

```text
5 ПП 45 ПП 100 С/П
```

Появится примерно `843,4673`; через `↔` доступна вторая координата. Обе координаты буя в этом примере равны `843,4673`.

## Регистры и показания

| Регистр | Значение |
| --- | --- |
| `R2` | шаг времени, минуты |
| `R3` | текущая масса балласта |
| `R4`, `R5` | координаты буя относительно аппарата |
| `R6`, `R7` | координаты цели относительно аппарата |
| `R8` | оставшийся ресурс, минуты |
| `R9` | глубина, м |
| `Ra` | предельная глубина; число заканчивается на `01` |
| `Rb` | глубина моря, м |
| `Rc`, `Rd` | сигналы аварии и обнаружения цели |
| `R0`, `R1` | рабочие значения хода и курса |

В тексте руководства глубина моря ошибочно отнесена к `R6`; код использует **`Rb`**, а `R6` занят координатой цели. При аварии `Ra` меняется на `88`; для ремонта восстановите исходный предел глубины в `Ra`. Новое путешествие начинайте со всей подготовки. Параметры движения и допустимость сброса балласта контролирует игрок.
