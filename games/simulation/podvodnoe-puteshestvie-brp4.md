# Подводное путешествие — БРП-4

- Автор программы в руководстве не указан.
- Источник: «Электроника БРП-4». Руководство по эксплуатации, программа №47. [Архив руководства](https://arbinada.com/pmk/pages/01057-library-docs.html).
- Байт-код: [дамп BRP4-2.BIN, опубликованный myak555](https://github.com/myak555/MK-52_Resurrect/blob/84693a122a2737169257edf6565b1aa8814b742e/MK-52_Sample_Programs/BRP%20Expansion%20Modules/BRP4-2.BIN); автор дампа — Сергей Фролов.
- Исходный адрес загрузки: `1270298`, переключатель БРП в положении `2`.
- Программа: [podvodnoe-puteshestvie-brp4.txt](podvodnoe-puteshestvie-brp4.txt)
- Модель: **МК-61**; объём: **98 команд**, адреса `00…97`.

## Задача

Управляйте исследовательским аппаратом «Эльвин»: меняйте ход, курс и сбрасывайте балласт, чтобы найти цель по гидроакустическим данным. Программа ведёт глубину, относительные координаты буя и цели и оставшийся ресурс. Превышение предельной глубины, удар о дно или исчерпание ресурса вызывают аварийное всплытие.

Это редакция БРП-4 программы [«Подводные аппараты»](podvodnye-apparaty.md). **По адресу `18` сохранена исходная команда `хП9`.** Напечатанная в руководстве на с. 184 рекомендация заменить её на `Пх9` ошибочна: чтение вместо записи замораживает глубину. Предыдущая версия импорта следовала этой рекомендации; теперь восстановлен байт ПЗУ `49`.

## Подготовка

Введите листинг, перейдите в `F АВТ`, установите угловой режим **`Г`**:

```text
3 хП2
1300 хП3
1000 хП4 хП5
1200 хП6 хП7
720 хП8
0 хП9
3001 хПa
3500 хПb
1 /-/ хПc
2 /-/ хПd
Cx В/О С/П
```

Первое показание — `0`, аппарат ожидает команду. Для удобства ручного ввода в этом запуске выбраны числовые сигналы: `−1` — авария, `−2` — цель найдена. Они задаются данными в `Rc`, `Rd`; исходное руководство использует буквенные сигналы `Г`, `Е00`.

Для работающего сценария начальный балласт равен **1300 кг**. В примере руководства на с. 185 напечатано 13000 кг, что с исходным кодом немедленно даёт аварийную глубину 35700 м. Нейтральный балласт в модели — 1000 кг; после сброса `Δp` глубина меняется по формуле `H = max(0, H + (P − 1000) × Δt)`, где `P` — оставшийся балласт. Положительный избыток балласта погружает аппарат, недостаток поднимает его.

## Управление

Введите **ход `V` от 0 до 10**, нажмите `ПП`; введите курс в градусах и снова `ПП`; введите массу сбрасываемого балласта `Δp` и нажмите `С/П`. Здесь `ПП` вводит параметры через стек возвратов — заменять его на `В↑` нельзя.

Контрольный манёвр:

```text
5 ПП 45 ПП 100 С/П
```

Появится примерно `843,4673`; через `↔` доступна вторая координата. Обе координаты буя равны `843,4673`, глубина в `R9` — **600 м**, ресурс в `R8` — 717 минут. Следующий манёвр `0 ПП 0 ПП 400 С/П` уменьшает балласт до 800 кг и возвращает аппарат на поверхность: `R9=0`.

## Регистры и показания

| Регистр | Значение |
| --- | --- |
| `R2` | шаг времени, минуты |
| `R3` | текущая масса балласта |
| `R4`, `R5` | координаты буя относительно аппарата |
| `R6`, `R7` | координаты цели относительно аппарата |
| `R8` | оставшийся ресурс, минуты |
| `R9` | глубина, м |
| `Ra` | предельная глубина; число заканчивается на `01` |
| `Rb` | глубина моря, м |
| `Rc`, `Rd` | сигналы аварии и обнаружения цели |
| `R0`, `R1` | рабочие значения хода и курса |

В тексте руководства глубина моря ошибочно отнесена к `R6`; код использует **`Rb`**, а `R6` занят координатой цели. Допустимость хода, курса и сброса балласта контролирует игрок.

## Аварийное всплытие и новая попытка

При аварии показывается `−1`, а `Ra` меняется на `88`. Последующие `С/П` выполняют аварийное всплытие: глубина уменьшается на `1000 × Δt` за шаг до нуля. Восстановите исходное значение `3001 хПa`, когда аппарат окажется в допустимой зоне. Если ресурс исчерпан, восстановите также `R8`, иначе авария повторится.

Например, при балласте 1300 кг и глубине 3100 м манёвр без движения и сброса балласта даёт аварийную глубину 4000 м. `3001 хПa С/П` поднимет аппарат до 1000 м и вернёт обычную остановку. Перед новой попыткой поиска надёжнее выполнить всю подготовку заново; это также восстанавливает координаты и ресурс.
