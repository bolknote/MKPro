# Зонд: Земля — Луна

- Автор: **darth.righter**
- Источники: [«Земля — Луна на ПМК. Алгоритм Кеплера»](https://darth-righter.livejournal.com/8358.html), [«Земля — Луна на ПМК. Е1 — старт и финиш»](https://darth-righter.livejournal.com/9037.html)
- Программа: [zond-earth-moon.txt](zond-earth-moon.txt)
- Серия: «Кон-Тики» / «Путь к Земле»

## Задача

Программа моделирует инерционный перелёт космического аппарата с околопланетной орбиты к спутнику планеты, который движется по круговой орбите. Двигатели аппарата во время расчёта выключены. Движение рассчитывается в полярной системе координат с центром в центре планеты, а угол отсчитывается от направления планета — спутник.

«Зонд» автоматически выбирает шаг времени: около Земли он составляет десятки секунд, а по мере удаления увеличивается примерно до 2000 секунд. Программа останавливается в двух случаях:

- аппарат вошёл в заданную сферу действия спутника — в `Р1` находится сообщение об успехе;
- вертикальная скорость стала отрицательной — аппарат достиг апогея и начал возвращаться к планете.

Модель учитывает притяжение центральной планеты. Притяжение спутника после входа в его сферу действия не рассчитывается.

## Регистры

| Регистр | Значение |
|---|---|
| `Р0` | горизонтальная скорость, м/с |
| `Р1` | сообщение об успешном достижении цели |
| `Р2` | текущий шаг времени, с |
| `Р3` | служебный: момент `M = v × r` |
| `Р4` | гравитационный параметр центральной планеты |
| `Р5` | число циклов автопилота |
| `Р6` | минимальная достигнутая дистанция до спутника со знаком минус, м |
| `Р7` | радиус сферы действия спутника, м |
| `Р8` | радиус орбиты спутника, м |
| `Р9` | служебный: константа `A = M × v − G` |
| `РА` | расстояние до центра планеты, м |
| `РВ` | вертикальная скорость, м/с |
| `РС` | угол между направлениями планета — спутник и планета — аппарат, рад |
| `РД` | свободен |
| `РЕ` | полное время полёта, с |

Установите переключатель угловых величин в положение `Р` — радианы.

## Пример: с низкой околоземной орбиты к Луне

Лётное задание из статьи: старт с круговой орбиты высотой 100 км в плоскости лунной орбиты и выход в сферу действия Луны.

Введите исходные данные:

```text
0 xП5 xПB xПE
1 ВП 5 В↑ 6371 ВП 3 + xПA FВx Fx² 9,81 × xП4
3844 ВП 5 xП8 /-/ xП6
6618 ВП 4 xП7
ИП4 ИПA ÷ F√ xП0
```

В `Р1` можно заранее записать собственное сообщение об успехе. Автор использует видеосообщение «В сфере действия Луны».

Начальный угол для гомановского перехода вычисляется последовательностью:

```text
ИПA ИП8 + ИП8 ÷ 2 ÷ В↑ В↑ × × F√ 1 - Fπ × xПC
```

Для приведённых исходных данных получится примерно `−2,0027075` рад. Начальная горизонтальная скорость вычисляется так:

```text
ИПA F1/x ИПA ИП8 + F1/x - 2 × ИП4 × F√ xП0
```

Результат — около `11001,359` м/с. Запустите программу командами `В/О С/П`.

В контрольном расчёте автора вход в сферу действия Луны произошёл через `349630,018` с — около 97 часов. Последний шаг составлял `2034,5722` с.

Чтобы продолжить расчёт до поверхности Луны, замените радиус сферы действия в `Р7` на радиус Луны и снова запустите программу:

```text
1738 ВП 3 xП7 В/О С/П
```

В статье столкновение происходит примерно через пять суток полёта; после этого продолжения `Р5` содержит 348 расчётных циклов. Лунное притяжение на этом участке по-прежнему не учитывается.
