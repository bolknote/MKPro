- Автор оригинала: **Peter G. Poloczek**

Это современная сокращённая игра по мотивам оригинала TI-59. Сохранены земля, зерно, население, голод, урожай, миграция, чума и крысы. Революция и подробный печатный отчёт не перенесены; формулы событий приведены ниже полностью.

## Задача

Управляйте государством десять лет. Старайтесь увеличить население, сохранив землю и запас зерна. В конце сравните эти три показателя с предыдущими партиями при том же начальном числе генератора. Отдельного звания победителя программа не присваивает.

## Подготовка

Загрузите листинг и перейдите в режим вычислений `F АВТ`. Угловой режим не влияет на игру. Введите:

```text
10 хП2
100 хП6
2800 хП1
1000 хП4
23 хП7
0,371825 хП8
997 хПa
20 хПb
97 хПc
10 хПd
96 хПe
```

`R8` — начальная дробь генератора. Для другой последовательности выберите дробь из шести или семи различных цифр между нулём и единицей. Простые дроби вроде `0,5` могут давать короткие циклы. Одинаковые начальные данные и приказы воспроизводят партию.

Запустите:

```text
В/О С/П
```

## Годовой ход

Программа показывает население, затем зерно и землю. После первых двух показаний нажимайте `С/П`. После земли введите три решения:

```text
изменение_земли С/П
число_накормленных_жителей С/П
земля_под_посев С/П
```

Покупка земли положительна, продажа отрицательна: `51 /-/ С/П` продаёт 51 единицу земли. Питание вводится **в людях**: `100` кормит 100 жителей за 2000 единиц зерна. Дробная часть числа накормленных отбрасывается. Земля при торговле и посеве может быть дробной.

Цену земли смотрите через `Пх7`, оставшиеся годы — `Пх2`. После просмотра вводите решение заново. После посева рассчитывается год; новое население начинает следующий отчёт.

## Проверка приказов

Для населения `N`, зерна `G`, земли `L`, цены `P`, торговли `Q`, накормленных `F` и посева `S` проверяются:

```text
L + Q >= 0
0 <= F <= N
0 <= S <= L + Q
S <= 10 × F
Q × P + 20 × F + S / 2 <= G
```

Голодные жители погибают до обработки земли, поэтому работают именно `F` выживших. Каждый обрабатывает до десяти единиц земли. Посев единицы земли требует половины единицы зерна. Продажа может покрыть расходы того же года.

Невозможный приказ даёт `ЕГГ0Г`, сохраняя население, зерно, землю, цену, год и генератор. Восстановите ввод:

```text
Cx В/О С/П
```

Снова просмотрите три показателя и повторите все три решения этого года.

## События года

Генератор получает `q = дробная_часть(997 × q)`. Из него последовательно извлекаются **пять разных цифр в системе счисления с основанием 6**: умножить рабочую дробь на 6, взять целую часть `d`, продолжить с дробной частью. Эти цифры `d1…d5` лежат в диапазоне `0…5`. Исходное годовое `q` хранится отдельно: извлечение цифр не уничтожает состояние для следующего года.

1. От голода остаётся `F` жителей.
2. Урожайность равна `d1 + 1`, то есть `1…6`.
3. Прибывает `d2` жителей, то есть `0…5`.
4. При `d3 = 0` чума уменьшает население после прибытия вдвое, с отбрасыванием дробной части.
5. К остатку зерна прибавляется урожай `S × (d1 + 1)`. Крысы уничтожают `5 × d4` процентов этой суммы: от `0` до `25%`.
6. Цена земли следующего года равна `20 + d5`.

Плохой урожай больше не означает автоматически чуму, фиксированную миграцию и определённую цену. Ошибочный приказ не расходует годовое случайное число.

## Завершение и пример

После десятого года индикатор показывает `0` — расчёт завершён. Итоги: население `Пх6`, земля `Пх4`, зерно `Пх1`. После просмотра верните итоговый экран через `С/П`. Для новой партии повторно введите начальные данные. После финиша `R2 = 1` из-за устройства `F L2`.

Голод уменьшает итоговое население; отдельного мгновенного проигрыша за потерю половины жителей в этой версии нет. Это правило прежней адаптации было добавлено мной и не сохраняется в новой модели оценки.

Контрольная партия для указанного начального числа:

| Год | Торговля | Накормить | Посев | Урожайность |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 0 | 100 | 1000 | 5 |
| 2 | 0 | 101 | 1000 | 3 |
| 3 | 0 | 103 | 1000 | 2 |
| 4 | 0 | 104 | 1000 | 1 |
| 5 | −51 | 109 | 949 | 2 |
| 6 | −34 | 111 | 915 | 2 |
| 7 | −50 | 113 | 865 | 4 |
| 8 | 0 | 113 | 865 | 6 |
| 9 | 0 | 113 | 865 | 3 |
| 10 | 0 | 113 | 865 | 2 |

Итог с точностью МК-61: население `117`, земля `865`, зерно примерно `2505,87`. При других начальных числах возможны чума, другие потери зерна и цены.

## Регистры

| Регистр | Содержание |
| --- | --- |
| `R0` | накормленные при вводе; затем урожайность |
| `R1` | зерно |
| `R2` | оставшиеся годы |
| `R3` | проверяемый земельный фонд |
| `R4` | земля |
| `R5` | посев |
| `R6` | население |
| `R7` | цена земли |
| `R8` | годовое состояние генератора |
| `R9` | торговля при вводе; затем рабочая дробь событий |
| `Ra`, `Rb` | постоянные `997` и `20` |
| `Rc` | адрес извлечения цифры, `97` |
| `Rd` | трудовая норма, `10` |
| `Re` | адрес ошибки, `96` |
