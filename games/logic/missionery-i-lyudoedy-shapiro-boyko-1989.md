# Миссионеры и людоеды

- Источник: **С. И. Шапиро, А. Б. Бойко. Программируемые микрокалькуляторы в обучении. Москва: Радио и связь, 1989.** С. 232. [Скан книги](https://nzdr.ru/data/media/biblio/games/prog/pmk_/%D0%9A%D0%BD%D0%B8%D0%B3%D0%B8/%D0%9F%D0%9C%D0%9A%20%D0%B2%20%D0%BE%D0%B1%D1%83%D1%87%D0%B5%D0%BD%D0%B8%D0%B8%20%281989%29%20-%20%D0%A8%D0%B0%D0%BF%D0%B8%D1%80%D0%BE.djvu).
- Авторы книги: С. И. Шапиро, А. Б. Бойко; отдельное авторство листинга не выделено.
- Программа: [missionery-i-lyudoedy-shapiro-boyko-1989.txt](missionery-i-lyudoedy-shapiro-boyko-1989.txt).
- Модель проверки: **МК-61**; **55 команд**, адреса `00…54`.
- Редакция: исходный листинг книги, без изменений байт-кода.

## Задача

Перевезите с левого берега на правый трёх миссионеров и трёх людоедов.
В лодке помещаются один или два человека; грести умеет каждый.
На берегу с миссионерами людоедов не должно быть больше, чем миссионеров.
Берег без миссионеров может содержать любое число людоедов.

Человек выбирает пассажиров для рейсов **слева направо**, ПМК — для
обратных рейсов. Это совместное решение головоломки. ПМК не выбирает
за человека весь маршрут.

## Подготовка

Введите листинг и перейдите в `F АВТ`. Переключатель углов — в любом
положении. Для новой переправы:

```text
3 хП4 хП5
0 хП2 хП3
```

`R4` и `R5` — людоеды и миссионеры слева, `R2` и `R3` — справа.
В книге общее число обозначено `n`, но игровой пример и эта карточка
рассчитаны на **три пары**. Остальные регистры заранее заполнять не нужно.

## Ход человека и ответ ПМК

Выберите `l` людоедов и `m` миссионеров для лодки и введите:

```text
l В↑ m В/О С/П
```

Здесь `l` и `m` заменяются числами, их сумма должна быть `1` или `2`.
Например, `1 В↑ 1 В/О С/П` отправляет по одному пассажиру каждого вида.
ПМК покажет код выполненного рейса `10·l+m`, в примере — `11`.

Затем нажмите **только `С/П`** — калькулятор выполнит обратный рейс:

| Код | Кто вернулся справа налево |
| --- | --- |
| `10` | один людоед |
| `1` (то же, что `01`) | один миссионер |
| `11` | людоед и миссионер |

После ответа снова вводите свой ход через `l В↑ m В/О С/П`.
Возврат к адресу `00` нужен **для каждого хода человека**.

Если последний рейс человека перевёз всех, сначала появится его обычный
код; после следующего `С/П` ПМК покажет `3,1415926` — задача решена,
обратного рейса нет. Остановитесь. Для новой игры повторите подготовку.

## Контрольный пример

Полное решение с первыми ходами из книги. В колонке «ход человека»
указаны пассажиры `l,m`, а не одно число для ввода:

| Ход человека `l,m` | Показан его код | Результат следующего `С/П` |
| --- | ---: | ---: |
| `1,1` | `11` | `1` |
| `2,0` | `20` | `10` |
| `0,2` | `2` | `11` |
| `0,2` | `2` | `10` |
| `2,0` | `20` | `10` |
| `2,0` | `20` | `3,1415926` — победа |

## Ограничения исходника

**Допустимость рейса проверяет человек.** Программа не отклоняет
пустую или перегруженную лодку, отсутствующих пассажиров и опасное
соотношение на берегах. Перед каждым ходом проверяйте оба берега.
Отдельной диагностики тупика тоже нет; неудачную переправу начните заново.

Код сохранён без изменений, дополнительные проверки не добавлены.
Команды косвенного вызова в обратных рейсах используются ради изменения
счётчиков пассажиров. `R0` и `R1` служат для текущего ввода;
`R2…R5` — состояние берегов. Значения других регистров для подготовки
не нужны. Нажатие `В/О` не обнуляет берега.

Проверка в эмуляторе МК-61: полная переправа, все достижимые допустимые
позиции с ответами ПМК, состояние обоих берегов, повторный запуск,
разные угловые режимы и подготовка после посторонних значений регистров.
Команда: `node tests/emulator/shapiro-boyko-1989.cjs` из корня репозитория.
