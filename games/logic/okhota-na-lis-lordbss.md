## Подготовка

```text
0.1234 хПe
```

## Игра

Нажмите `В/О С/П`. Ноль означает, что восемь лис расставлены на поле 10×10.
Введите координаты дробью `А,Б`, где обе цифры от 0 до 9, и нажмите `С/П`.
Число на экране — сколько ещё не пойманных лис видно по горизонтали, вертикали и диагоналям.

`LIS-N` означает поимку: N — сколько лис осталось. В одной клетке может быть несколько лис;
повторяйте ввод такой клетки для поимки каждой. После `LIS-0` все лисы пойманы.
R5 содержит количество попыток, R3 — последний ход.
Для новой расстановки повторите подготовку с другим дробным зерном.
