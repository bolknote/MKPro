# Раздаём карты и числа

- Автор книжных правил: **Csákány Antal**
- Адаптация и листинг для МК-61: **OpenAI Codex, 2026 год**

- Модель: МК-61, **104 команды**, адреса `00…A3`; запуск с `53`

## Правила

Из французской колоды удаляют картинки и джокеров. Остаётся 40 карт: по четыре экземпляра значений `1…10`; туз считается единицей. Масти на результат не влияют.

Разложены три закрытых столбца по семь карт, остальные 19 составляют запас. Верхние карты трёх столбцов открывают и перемножают. Затем из запаса раздают **две карты**. Если произведение делится без остатка на значение каждой из них, снимают всю пятёрку: три верхние карты и два делителя. После этого открывают следующую тройку.

Если хотя бы одно частное дробное, верхняя тройка остаётся на месте, неудачная пара уходит в отбой и раздаётся следующая пара. Проверяются два отдельных деления: произведение не обязано делиться на произведение двух делителей.

Например, для тройки `3, 10, 9` произведение равно `270`. Пара `6, 7` не подходит, поскольку `270 ÷ 7` дробно. Следующая пара `2, 6` подходит: частные равны `135` и `45`. Это пример из книги.

Победа — снять все семь троек. Из 19 карт запаса получаются девять полных пар; последняя одиночная карта остаётся без пары. Если девять пар закончились раньше, пасьянс не сошёлся.

Здесь, как в книжном описании, пары **раздают**, а не выбирают среди всех карт. Это автоматический пасьянс: исход определяется раздачей. Перед проверкой пары можно самостоятельно предсказывать делимость; программа не запрашивает ответ и не ведёт счёт правильных ответов.

## Подготовка

Введите листинг, перейдите в автоматический режим и подготовьте регистры:

```text
7 хП1
9 хП2
0 хП3 хП4
0,00001 хПa
981 хПb
3 хПc
20 хПd
```

Положение переключателя углов не имеет значения. Для контрольной партии введите начальное число `161` и запустите с адреса `53`:

```text
161 В/О БП 53 С/П
```

Первый результат — `−90`, произведение верхней тройки со знаком минус. Дальше нажимайте только `С/П`. Новых чисел вводить не требуется; случайный числовой ввод на промежуточной остановке не меняет раздачу или проверку пары.

Для новой партии заново выполните **всю подготовку регистров**, затем запуск с `53`. Начальное число можно заменить любым целым от `0` до `99999`. Программа сама отбрасывает дробную часть и знак; более крупные числа также приводятся к состоянию генератора, но из-за округления калькулятора могут совпадать с другими начальными числами. Отдельного параметра шага и ручного вычисления констант нет.

## Остановки программы

| Показание | Значение | Что делает следующее `С/П` |
| --- | --- | --- |
| **Отрицательное число `−P`** | Произведение текущей верхней тройки равно `P` | Раздаёт и показывает пару делителей |
| **Положительное число от `101` до `1010`** | Два делителя, записанные как `100 × u + v` | Проверяет пару и продолжает раздачу |
| **`0`** | Победа: сняты все семь троек | Сохраняет итог |
| **`1`** | Поражение: запас пар исчерпан | Сохраняет итог |

Пару читайте двумя двузначными группами, дополняя слева нулём: `309` означает **03 и 09**, `604` — **06 и 04**, `110` — **01 и 10**, `1010` — **10 и 10**.

После проверки подходящей пары появляется новое отрицательное произведение или итог партии. После неподходящей пары сразу показывается следующая положительная пара, а произведение остаётся прежним. При исчерпании запаса появляется итог `1`, даже если последняя пара подошла, но не сняла последнюю тройку. Снятие седьмой тройки девятой парой даёт победу `0`.

Каждая новая тройка показывается один раз своим произведением; отдельных остановок на трёх картах нет. В контрольной партии всего **17 остановок**, включая итог. При окончании продолжайте только `С/П`: ручной ввод числа заменяет показание индикатора.

## Регистры

| Регистр | Значение |
| --- | --- |
| `R0` | внутренний счётчик трёх карт для `F L0` |
| `R1` | счётчик троек для `F L1`, начальное значение 7 |
| `R2` | счётчик пар для `F L2`, начальное значение 9 |
| `R3`, `R4` | две целые битовые маски уже выданных физических карт, начальные значения 0 |
| `R5` | состояние генератора в виде дроби с пятью знаками |
| `R6` | номер кандидата в колоде, `0…39` |
| `R7` | временная степень двойки; на остановке с парой — второй делитель |
| `R8` | положительное произведение текущей тройки |
| `R9` | селектор маски: 3 или 4 |
| `Ra` | приращение генератора, `0,00001` |
| `Rb` | множитель генератора, 981 |
| `Rc` | адрес подпрограммы раздачи, 3 |
| `Rd` | число битов в одной маске, 20 |
| `Re` | первый делитель; при проверке — дробная часть первого частного |

Команды `F L0…L2` оставляют в исчерпанном счётчике единицу. Поэтому после завершения `R1` и `R2` не следует читать как точное число оставшихся троек и пар; ориентируйтесь на итог `0` или `1`.

## Как построена колода

У каждой физической карты свой номер `k` от `0` до `39`; значение карты равно `1 + целая_часть(k ÷ 4)`. Уже выданный номер помечается в одной из двух масок по 20 бит и второй раз не принимается. Это гарантирует не более четырёх экземпляров каждого значения, включая карты в отбое. Если продолжить раздачу до 40 карт, получится ровно по четыре экземпляра каждого ранга.

Кандидаты выбираются генератором:

```text
S(0) = |целая_часть(начального числа)|, для чисел 0…99999
S(n+1) = (981 × S(n) + 1) mod 100000
k = целая_часть(S(n+1) ÷ 2500)
```

На МК-61 хранится дробь `S ÷ 100000`. Генератор имеет период 100000 состояний; занятые кандидаты пропускаются. При вычислении битовой маски степень двойки округляется до целого: без этого погрешность `F x^y` повреждала бы учёт карт.

Карты выбираются при первом открытии: три для новой верхней тройки и две для каждой пары. Закрытые карты заранее не хранятся. При независимом равномерном выборе из оставшихся карт такой порядок открытия эквивалентен заранее перемешанной колоде; использованный конечный псевдослучайный генератор лишь приближает такую тасовку и не даёт равномерного выбора из всех `40!` перестановок.

## Отличия и уточнения адаптации

- В источнике описана настольная игра для обычного калькулятора; программного листинга нет. Здесь раздача и проверка выполняются самой программой.
- **Отбой без возврата — выбранное правило этой версии.** Книжное описание не устанавливает порядок возврата или повторного использования неудачных пар. Поэтому девять попыток и неиспользуемая одиночная карта относятся именно к этому варианту.
- Показано только произведение тройки и два делителя. Масти и закрытые карты не отображаются; физическая колода для игры не требуется.
- Программа не предлагает тактического выбора и не оценивает ответы игрока. Её можно использовать как арифметическое упражнение, предсказывая результат проверки до нажатия `С/П`.

Проверка в эмуляторе: `node tests/emulator/csakany-cards-numbers.cjs`. Она использует подготовку из этой карточки, сверяет полные партии с независимой целочисленной моделью и проверяет состав колоды, округление масок, нормализацию начального числа и книжный пример делимости.
