## Игра

Нажмите `С/П`: на экране **9**, столько камней в кучке. Играют **два человека**.
По очереди вводите целое число от 1 до 3 и нажимайте `С/П`. ПМК показывает остаток.
Взявший последний камень выигрывает; его ход заканчивается сигналом **1000**.
Для новой партии нажмите `В/О С/П`.

Нулевой, отрицательный, дробный ход, число больше трёх или больше остатка вызывают `ЕГГОГ`.
Кучка при ошибке не меняется. Для исправления нажмите `Сх`, введите допустимый ход,
затем `БП 09 С/П`: этот ход принадлежит тому же игроку. Повторный `В/О С/П` начинает новую партию.

## Исправления исходника

Исходная программа разрешала дробные ходы и засчитывала победу при переборе камней:
последовательность `3, 3, 1, 3` выигрывала при оставшихся двух камнях.
В каталоге сохранены начальная кучка, правила, управление и размер исходного файла — **50 команд**.
Проверки в блоке **21–45** заменены проверкой целого хода, неотрицательного остатка
и точного нуля для победы; переходы **14** и **20** перенаправлены на обработчик ошибки **41**.
Хвост **46–49** остаётся нулевым. Сохранён исходный код до исправления в контрольной фикстуре теста.
Вывода `1111`, обещанного README автора, в опубликованном коде нет: для двух людей
достаточно сигнала победы последнего ходившего.
