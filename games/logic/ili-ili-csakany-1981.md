## Правила

Из французской колоды убирают картинки и джокеров. Остаются 40 карт: по четыре значения `1…10`; туз считается единицей. Десять закрытых карт сопоставлены цифрам калькулятора `0…9`.

На каждом ходу выберите ещё не использованную пару и решите, что взять: известную цифру или неизвестную карту рядом с ней. Выбранное значение прибавляется к вашему счёту. После десяти ходов использованы все пары.

**Каждая пара используется только один раз.** Это уточнение адаптации: книга задаёт десять ходов и десять пар, но отдельно не запрещает повторный выбор. Здесь запрет введён явно и проверяется программой; без него можно было бы десять раз брать цифру 9.

В одиночной игре цель — набрать большую сумму. Ориентиры автора: **50 очков — приемлемый результат, 70 — отличный**. Это ориентиры оценки, а не автоматический конец партии. Невыбранные карты не показываются.

Вдвоём игроки ходят по очереди. Выбравший получает выбранный элемент пары, соперник — второй. Например, при цифре `8` и карте `3` выбор цифры даёт ходящему 8 очков, сопернику 3; выбор карты распределяет их наоборот. Выигрывает набравший большую сумму; возможна ничья. Начинающего, как предлагает книга, определите жребием и назовите игроком A. Второй будет B.

Физическая колода не нужна: карты выдаёт калькулятор, соблюдая ограничение в четыре экземпляра каждого значения.

## Подготовка

Введите листинг, перейдите в автоматический режим и подготовьте регистры:

```text
4 хП0 хП1 хП2 хП3 хП4 хП5 хП6 хП7 хП8 хП9
10000 хПa
10 хПb
```

Для **одиночной игры**:

```text
100 хПe В/О С/П
```

Для **игры вдвоём** вместо этого:

```text
101 /-/ хПe В/О С/П
```

Положение переключателя углов не имеет значения. В обоих случаях появится `10000` — начальный счёт `1 00 00`.

Для новой партии заново выполните **всю подготовку** и запуск выбранного режима. Во время игры `В/О С/П` возвращает текущий счёт без потери хода. После окончания та же последовательность возвращает отрицательный итог и не возобновляет выбор пар.

## Выбор и ввод хода

Положительный код берёт известную цифру, отрицательный — закрытую карту той же пары:

| Пара у цифры | Взять цифру | Взять карту |
| ---: | ---: | ---: |
| 0 | `1` | `−1` |
| 1 | `2` | `−2` |
| 2 | `3` | `−3` |
| 3 | `4` | `−4` |
| 4 | `5` | `−5` |
| 5 | `6` | `−6` |
| 6 | `7` | `−7` |
| 7 | `8` | `−8` |
| 8 | `9` | `−9` |
| 9 | `10` | `−10` |

Введите код и нажмите `С/П`. Для отрицательного кода сначала введите модуль, затем нажмите `/-/`. Например:

```text
10 С/П
```

Берёт известную девятку. Пара у цифры 9 после этого недоступна.

```text
1 /-/ С/П
```

Берёт карту у цифры 0. Её значение в одиночной игре равно приращению вашего счёта. Вдвоём при выборе карты соперник получает известную цифру; при выборе цифры соперник получает карту. Поэтому по изменению двух счетов видны оба результата хода.

В одиночном режиме все десять решений принимает один игрок. Вдвоём A выбирает на ходах 1, 3, 5, 7, 9, B — на ходах 2, 4, 6, 8, 10. Запоминайте или отмечайте использованные цифры; повтор программа отклонит.

## Показания программы

Счёт записан пятью цифрами **`1 AA BB`**: первая единица служебная, следующие две цифры — очки A, последние две — очки B.

| Показание | Значение |
| --- | --- |
| `10000` | Начальный счёт 0:0 |
| `16300` | В одиночной игре набрано 63 очка; поле B всегда `00` |
| `13237` | Вдвоём: A набрал 32, B — 37; ожидается следующий выбор |
| `−16300` | Одиночная партия закончена: 63 очка |
| `−13237` | Партия вдвоём закончена: 32:37, победил B |
| `−1` | Ошибочный код или уже использованная пара |

После **десятого принятого хода** счёт показывается со знаком минус. Повторное `С/П` и `В/О С/П` сохраняют итог и не выдают новых карт. Число ходов, очки и карты не меняются и при случайном числовом вводе на итоговой остановке.

Допустимы только целые коды `±1…±10`. Ноль, дроби, числа вне диапазона и повторный выбор пары дают `−1`, сохраняя очки, число ходов и оставшиеся карты. При `−1` нажмите `С/П`: снова появится счёт, после чего введите другой код. Простой `С/П` на остановке со счётом тоже не является ходом: показанный счёт не входит в допустимый диапазон кодов.

## Контрольная партия

Для простой проверки выберите одиночный режим и возьмите все известные цифры по возрастанию. Каждый код вводится перед своим `С/П`:

```text
1 С/П 2 С/П 3 С/П 4 С/П 5 С/П
6 С/П 7 С/П 8 С/П 9 С/П 10 С/П
```

Показания после принятых ходов:

```text
10000 10100 10300 10600 11000
11500 12100 12800 13600 −14500
```

Итог — **45 очков**, сумма цифр от 0 до 9. От случайных карт этот контроль не зависит. Для результата выше 45 придётся рисковать и выбирать закрытые карты.

## Регистры

| Регистр | Значение |
| --- | --- |
| `R0…R9` | целая часть — число оставшихся карт значения `номер регистра + 1`; дробная часть `0,5` означает, что пара у соответствующей цифры уже использована |
| `Ra` | счёт `10000 + 100 × A + B`; в одиночном режиме B равен 0 |
| `Rb` | число оставшихся ходов; в игре вдвоём знак указывает следующего ходящего: плюс — A, минус — B; после окончания 0 |
| `Rc` | код хода, затем вес известной цифры при начислении очков |
| `Rd` | временный селектор регистра; на остановке после хода — значение последней выданной карты |
| `Re` | режим: `100` для одиночной игры или `−101` для двух игроков |

При выборе известной цифры в одиночном режиме последняя выданная карта скрыта. Просмотр `Rd` или анализ оставшихся карт через `R0…R9` раскроет информацию, которой нет в обычном ходе игры.

## Устройство адаптации

В книге приведены настольные правила и способ записи двух счетов обычным калькулятором; программного листинга нет. Здесь программа проверяет выбор, хранит использованные пары и состав колоды, начисляет очки обоим участникам и останавливает партию после десяти ходов. Вместо книжной записи двух счетов восемью цифрами используется пятизначный формат с двумя двузначными полями. Очки каждого участника остаются меньше 100: десяток в колоде только четыре, а остальные получаемые значения не больше 9.

Карты назначаются парам при их первом выборе. Для ещё не открытых карт независимый равномерный выбор из оставшейся колоды эквивалентен предварительной раздаче. Используется встроенный псевдослучайный генератор `К СЧ`, поэтому равномерный выбор из всех перестановок не гарантируется и задаваемого пользователем начального числа нет.

Для результата генератора `u` ранг определяется целой частью `10 × u`, а номер копии — целой частью `4 × дробная_часть(10 × u)`. Получаются десять рангов по четыре равных интервала предложений. Предложение принимается, только если номер копии меньше оставшегося количества карт этого ранга. После принятия количество уменьшается на единицу. При равномерных предложениях это даёт выбор пропорционально оставшемуся числу копий, а не равновероятный выбор среди ещё не исчерпанных рангов. Выданные карты в колоду не возвращаются.

При повторной попытке в регистре стека Y сохраняется предыдущий дробный результат `К СЧ`. Возврат к генератору только с целыми рабочими значениями вызывал в эмуляторе короткий цикл при исчерпании ранга; этот случай исправлен и включён в проверку раздачи.

При выборе цифры карта также расходуется: вдвоём её получает соперник, в одиночном режиме она уходит закрытой в отбой. В одиночном режиме поле B остаётся нулевым и не раскрывает эту карту. Выбранная пара целиком выбывает в обоих режимах.

Проверка в эмуляторе: `node tests/emulator/csakany-either-or.cjs`. Тест использует подготовку из этой карточки, проверяет полные партии в обоих режимах, начисление очков по отдельной модели правил, состав колоды, защиту от повторов и неверного ввода, перезапуск и сохранение итога.
