# Чёт-нечёт-1

- Автор: Сергей Храмов; по программе Л. М. Финка
- Источник: [публикация и листинг](https://davaite-poigraem.1c-umi.ru/filemanager/download/345/)
- Дополнительный источник: [архивная публикация](https://habr.com/ru/articles/125484/)
- Программа: [odd-even-1.txt](odd-even-1.txt)
- Модель: Б3-34 / МК-54; без адаптации несовместима с МК-61/52

## Подготовка

```text
В/О
```

## Совместимость

Оригинал для **Б3-34/МК-54/МК-56**. Команда **04 = КП↑** в листинге записана
кодом `BE` (`КхПE`). В этих моделях она обращается через R0 без его уменьшения.
На МК-61/МК-52 `BE` обращается через отдельный RE, поэтому прямой запуск несовместим.
В эмуляторе выберите модель МК-54. Для МК-61 используйте [«Чёт-нечёт-3»](chet-nechet-3.md).

## Игра

Нажмите `С/П`: появится `0`. Введите `0` или `1`, нажмите `С/П` — появится прогноз ПМК.
Нажмите `С/П` ещё раз — появится счёт, умноженный на 1000.
Ошибочный прогноз даёт человеку очко, верный отнимает очко.
Играйте до `10000` или `−10000`; программа сама не завершает партию на этой границе.
Новая партия — `В/О С/П`.

## Восстановление

72 команды восстановлены по авторскому PDF, включая первоначальное обнуление памяти.
В старом импорте код **04** был потерян, а блоки программы переставлены.
Это восстановление исходника Б3-34, без адаптации под МК-61.
