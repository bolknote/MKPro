# Быки и коровы-2 — редакция Храмова

- Автор: редакция Сергея Храмова; «Наука и жизнь», 1989, №12
- Источник: [публикация и листинг](https://davaite-poigraem.1c-umi.ru/filemanager/download/356/)
- Дополнительный источник: [архивная публикация](https://xvadim.github.io/xbasoft/pmk/bullscows.zip)
- Дополнительный источник: [копия архива в статье illi4](https://habr.com/ru/articles/125484/)
- Программа: [byki-i-korovy.txt](byki-i-korovy.txt)
- Модель: Б3-34 / МК-54; без адаптации несовместима с МК-61/52

## Подготовка

```text
0 хП5 10 хПa 81 хПb 0.1234
```

## Совместимость

Это оригинал для **Б3-34/МК-54**, использующий `КИП↑`/`КП↑` с обращением через R0.
На МК-61/52 соответствующие коды `DE/BE` работают через RE; прямой запуск несовместим.
В эмуляторе выберите МК-54. Адаптация для МК-61 здесь не выполнялась.

## Игра

Нажмите `В/О С/П`. Введите четырёхзначную догадку и нажмите `С/П`.
Цифры секрета могут повторяться. Ответ имеет вид `БК`: число быков и число коров.
Бык — совпадение цифры и позиции, корова — совпадение цифры без позиции.
При повторяющихся цифрах программа считает все попарные совпадения, поэтому число коров
может отличаться от обычных правил с однократным использованием каждой цифры.
После точного ответа вместо подсказки появляется число попыток в виде периодической дроби:
`1,010101` — одна попытка, `12,121212` — двенадцать. Оценку игрок определяет сам:
до восьми попыток — «5», 9–11 — «4», 12–14 — «3», от пятнадцати — «2».
Для новой партии задайте новое дробное зерно и нажмите `В/О С/П`.
После выигранной партии начальный показ равен `4`, что нормально для авторского кода.
Для начала с ведущими нулями ориентируйтесь на четыре позиции, даже если ПМК скрывает нули слева.
