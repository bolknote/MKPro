# ПМК отгадывает цифры

- Авторы книги: **С. И. Шапиро, А. Б. Бойко**; автор листинга отдельно не указан.
- Источник: **Программируемые микрокалькуляторы в обучении. Москва: Радио и связь, 1989. С. 138–141; листинг на с. 140.** [Скан книги](https://nzdr.ru/data/media/biblio/games/prog/pmk_/%D0%9A%D0%BD%D0%B8%D0%B3%D0%B8/%D0%9F%D0%9C%D0%9A%20%D0%B2%20%D0%BE%D0%B1%D1%83%D1%87%D0%B5%D0%BD%D0%B8%D0%B8%20%281989%29%20-%20%D0%A8%D0%B0%D0%BF%D0%B8%D1%80%D0%BE.djvu).
- Программа: [pmk-otgadyvaet-tsifry-shapiro-boyko-1989.txt](pmk-otgadyvaet-tsifry-shapiro-boyko-1989.txt).
- Проверено в эмуляторе **МК-61**.
- Объём: **28 команд**, адреса `00…27`. Все напечатанные байты сохранены.

## Правила

Задумайте четыре цифры `0…9`. Повторы и начальные нули разрешены:
например, `0000`, `0017`, `9999`. ПМК определяет **набор цифр с учётом
повторов**, но не их порядок. Поэтому `1532`, `1235` и `5321` для этой
игры — одна цель.

На каждое предложение ПМК сообщайте, сколько цифр из вашего набора
в нём есть. Каждый экземпляр цифры используется только один раз:
для секрета `0017` предложение `0000` получает ответ `2`, а не `4`;
для секрета `1112` предложение `1111` — ответ `3`.

## Подготовка

Введите листинг и перейдите в `F АВТ`. Константы и определённый угловой
режим не нужны:

```text
В/О С/П
```

Первый `0` на индикаторе читайте как предложение **`0000`**.

## Ходы и окончание

Введите количество общих цифр — целое `0…4` — и нажмите `С/П`.
Появится новое предложение. Числа короче четырёх разрядов мысленно
дополняйте нулями слева: `19` означает `0019`.

Когда состав полностью совпал, введите **`4 С/П`**. ПМК покажет `0` —
поиск завершён. Это другой смысл нуля, чем при первом предложении.
Последний угаданный набор — число, показанное **до** этого ответа.

Алгоритм сохраняет уже найденные меньшие цифры и последовательно
увеличивает остальные. При честных ответах требуется не более десяти
предложений, считая `0000`: число предложений равно максимальной
задуманной цифре плюс один. Стратегию и таблицу команд источника
не меняли.

Программа не проверяет достоверность ответа и диапазон `0…4`.
Неправильные сведения нарушают дальнейший поиск. Для новой игры
снова выполните `В/О С/П`.

## Контрольная партия

Задумано `1532`:

| Предложение ПМК | Ваш ответ | Следующее показание |
| --- | ---: | --- |
| `0000` | `0 С/П` | `1111` |
| `1111` | `1 С/П` | `1222` |
| `1222` | `2 С/П` | `1233` |
| `1233` | `3 С/П` | `1234` |
| `1234` | `3 С/П` | `1235` |
| `1235` | `4 С/П` | `0`: задача решена |

репозитория. Тест использует фикстуру с адресом книги, SHA-256
