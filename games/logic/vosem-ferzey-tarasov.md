- Автор: Сергей Тарасов
- Источник: [публикация и листинг](https://github.com/sergev/mk-61/blob/296d766ea0861d19f7b85b624b38757307c17288/programs/queens.pmk)

- Модель: МК-61 / МК-52

## Подготовка

```text
В/О
```

## Задача

Программа автоматически ищет одну расстановку восьми ферзей на доске 8×8.
Это помощник для шахматной задачи: ходы игрока во время поиска не требуются.

## Запуск и результат

Нажмите `С/П` и дождитесь остановки с `0`. Расчёт длительный.
В регистрах **R1–R8** находятся номера горизонталей ферзей на вертикалях **a–h**.
Читайте их через `Пх1`, …, `Пх8`. Контрольное решение:

```text
a8 b4 c1 d3 e6 f2 g7 h5
```

В каждой строке и каждом столбце стоит ровно один ферзь, общих диагоналей нет.
Для повторного поиска с начала нажмите `В/О С/П`.
