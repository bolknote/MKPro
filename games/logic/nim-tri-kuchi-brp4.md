# Ним с тремя кучами — БРП-4

- Автор программы в руководстве не указан.
- Источник: «Электроника БРП-4». Руководство по эксплуатации, программа №34. [Архив руководства](https://arbinada.com/pmk/pages/01057-library-docs.html).
- Байт-код: [дамп BRP4-2.BIN, опубликованный myak555](https://github.com/myak555/MK-52_Resurrect/blob/84693a122a2737169257edf6565b1aa8814b742e/MK-52_Sample_Programs/BRP%20Expansion%20Modules/BRP4-2.BIN); автор дампа — Сергей Фролов.
- Исходный адрес загрузки: `1050498`, переключатель БРП в положении `2`.
- Программа: [nim-tri-kuchi-brp4.txt](nim-tri-kuchi-brp4.txt)
- Модель: **МК-61**; объём: **98 команд**, адреса `00…97`.

## Правила

Три кучки содержат от 0 до 99 предметов. За ход берут любое положительное число предметов из одной кучки. **Взявший последний выигрывает.** БРП-4 использует отдельный алгоритм и листинг, отличный от [нима Трохименко](nim-tri-mnozhestva-c3000.md).

## Подготовка

Введите листинг, перейдите в `F АВТ`:

```text
29 хП7
30 хП8
23 хП9
В/О С/П
```

Появится `1293023`. Первая единица служебная, далее идут три двузначных остатка: `1 29 30 23`. Угловой режим произвольный.

## Ходы

Первое `С/П` делает ход ПМК: `−1093023`, то есть 9, 30 и 23. Для своего хода занесите новые остатки в `R7`, `R8`, `R9` и нажмите `С/П`; увидите положительную позицию. Ещё одно `С/П` делает ответ ПМК. Знак минус означает очередь человека.

Контроль из руководства:

| Ход человека | Ответ ПМК |
| --- | --- |
| 9, 26, 23 | 9, 26, 19 |
| 9, 18, 19 | 1, 18, 19 |
| 1, 18, 8 | 1, 9, 8 |
| 1, 0, 8 | 1, 0, 1 |
| 0, 0, 1 | 0, 0, 0 |

`1000000` по модулю — все кучки пусты. В последней строке выигрывает ПМК. Проверку того, что за ход уменьшена ровно одна кучка, ведут участники. Для новой партии снова задайте все три кучки и выполните `В/О С/П`.
