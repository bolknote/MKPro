# Complete selector-family release

A literal-preloaded register can serve both as data and as a stable indirect
flow address. Keeping every flow indirect pins a component even when another
layout would save more cells overall. Pairwise exchanges cannot express
removing that constraint altogether.

The joint layout search retains those exchanges and also considers a complete
family release. Every flow through one immutable selector becomes its direct
counterpart and an operand naming the same command identity. Its preload is
unchanged. Companion selectors are independently rebound by the existing proof.

Release requires an unwritten R7..Re register with literal setup and a single
complete, authoritative target family. Generated setup, stale targets, unknown
writes and aliases, unstable selectors and dynamic charge families reject.
Calls, jumps and conditionals reuse the displaced-flow proof. Different X2
effects must be equal at entry or converge before an observer; both outcomes
and exact return contexts matter.

The final gate still checks command identities, external entries, stack and
hidden state, return continuations, indirect memory, data projections and
delivered selectors. Unresolved physical addresses never become runtime values.

Enumeration is deterministic, with at most one release attempt per stable
register. Every added operand must fit the caller's remaining global growth
allowance. The established search runs unchanged and retains its winner first:
new alternatives cannot evict its successful paths from a bounded beam. A
separate extension starts from that winner with at most four expansions,
24 candidates and depth three. Debt is measured against this new root for the
entire extension path, not renewed by each pass. Intermediate growth is reported
as debt; only a smaller complete artifact can win.

The compiler/ROM regression relocates a conditional target while retaining its
selector word as observable data. Its intermediate baseline is 19 to 20 cells.
Both outcomes, nested returns, stack and data are compared on the emulator.
A live decimal-entry X2 observer rejects the rewrite. Further negatives cover
zero/exhausted allowance, writes, aliases, stale targets, generated setup, and
unsupported or duplicate registers. No source, label, function or game name
is used to discover an opportunity.
