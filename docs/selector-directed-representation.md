# Selector-directed representation composition

The representation search can revisit a complete laid-out artifact. It first
normalizes supported overflow operands, binds numeric flow references to opaque
command labels, and validates the existing decimal selector charges. Stale
charges, executable address words and unsupported dark entry contracts reject
the transaction. Position annotations from a completed finalization pass are
discarded only after real references have acquired command identities.

Late selector roles remain local rewrite barriers rather than disabling the
whole arithmetic pass. Every unchanged indirect target retains its original
address; component permutation must prove exact control flow and return frames.
The stock empty-return continuation remains physical 01. Arithmetic changes
still require the existing finite-domain, alias, stack, X1 and X2 proofs. This
does not grant permission to retune a constant's observable data projection.

The relational execution graph also tracks freshly entered one/two-digit
ordinary selector values. A value may pass through calls, returns, jumps and
stores to a shared dispatch register. Its first indirect invocation can then
exclude incompatible encoded counters, not just combinations inconsistent with
an earlier invocation. The analysis does not infer numeric values from a taken
target: different raw words and dark aliases can have the same physical target.

Only stable R7..Re selectors participate. Unknown writes and aliases invalidate
their facts; raw operations and user resume forget the environment. Fresh-entry
proof is mandatory, so digits appended to an unknown mantissa or exponent do
not become integer constants. The graph has the existing deterministic state
bound and falls back to the conservative proof on exhaustion.

Compiler/ROM regressions cover a first-callback stack deletion, a literal
transported through a shared callee store, unknown entry/write/resume barriers,
and a seven-cell arithmetic reduction in an already marked artifact. Neither
source names nor application-specific constants select these transformations.
