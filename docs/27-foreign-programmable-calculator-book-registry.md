# Реестр книг о программируемых калькуляторах на других языках

Состояние на 23 октября 2026 года. В реестр включены исходный список и книги,
найденные при поиске игровой литературы. Файл считается **полученным полностью**
только после проверки титульной страницы, числа страниц и последней страницы.
Доступ в браузерном просмотрщике сам по себе полным скачиванием не считается.

Общий объём полученных материалов — около 117 МиБ. Контрольные суммы
сохранены отдельно. Ссылки в реестре ведут на публичные источники.

Разбор игровых разделов и сверка с текущим каталогом вынесены в
[`28-downloaded-book-games-audit.md`](./28-downloaded-book-games-audit.md).

## Приоритет дальнейшего разбора игр

1. **Poloczek, *Spiele*** — полный скан и десять явно названных игр с
   программами; это первый кандидат на сравнение с нашим каталогом.
2. **Csákány, *Mit tud a zsebszámológép?*** — выборка неполная, но часть игровой
   главы сохранена и содержит конкретные правила игр и задач.
3. **Бялоўскі, раздел 5.3.1** — новых листингов не даёт, зато называет несколько
   дошкольных игр для ПМК, которые стоит проверить по другим источникам.
4. **Romanovskis, *Taskuarvutist nii ja teisiti*** — сохранён полный комплект из
   125 страниц; теперь книгу можно OCR-распознать и проверить на новые игры локально.

Платные страницы, библиотечную выдачу и защиту браузера не обходили. Поэтому
статус «не получено» означает отсутствие законно доступного открытого файла на
момент проверки, а не отсутствие книги в библиотеках вообще.
